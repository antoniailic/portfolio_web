# antoniailicb.com

Web del portafolio. HTML/CSS/JS plano, sin build. Construida desde el Figma "Portfolio — claude".

- `site/` — la web publicada (Netlify publica esta carpeta; ver `netlify.toml`).
- `tools/` — scripts Python que generan las páginas de casos (`python3 tools/build_rest.py`, etc.).

Cada push a `main` se publica solo en Netlify.

Fuentes provisionales: Inter (en lugar de Unica77) y Xanh Mono (en lugar de Right Serif Mono) hasta tener las licencias.
